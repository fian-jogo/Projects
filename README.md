## Projects

### 📐 [Math Website](./MATH%20WEBSITE.html)
A complete, self-contained learning platform covering the full Indonesian junior-to-senior-high-school (SMP–SMA) mathematics curriculum, from basic arithmetic and algebra to calculus, trigonometry, statistics, and probability. Organized into clearly structured topic sections (Aritmatika, Aljabar, Geometri, Kalkulus, Trigonometri, Statistika dan Peluang, and more), with a collapsible sidebar navigation for easy browsing. The largest module in this repository, at over 3,000 lines of structured, semantic code.

### ⚛️ [Physics Website](./PHYSICS%20WEBSITE.html)
An educational reference organized around 8 progressive learning phases, from basic kinematics and Newtonian dynamics through fluids, thermodynamics, waves and sound, optics, electricity and magnetism, and modern physics (quantum phenomena, atomic and nuclear physics). Designed to guide a student from foundational mechanics to advanced modern physics topics in a logical sequence.

### 🧪 [Chemistry Website](./CHEMISTRY%20WEBSITE.html)
Covers the complete SMP–SMA chemistry curriculum, structured from A to K: introduction to matter, atomic structure, the periodic table, chemical bonding, stoichiometry, solution chemistry, thermochemistry, reaction kinetics, chemical equilibrium, and redox reactions and electrochemistry.

### 🧬 [Biology Website](./BIOLOGY%20WEBSITE.html)
Structured from fundamental to advanced topics: the characteristics of life, cell biology, human organ systems, ecology, genetics, microbiology, molecular biology, evolution, and plant physiology, including both classical and modern biotechnology.

### 🌐 [IELTS Website](./IELTS%20WEBSITE.html)
A standalone website built to support IELTS exam preparation.

## Tech Stack

- **HTML5** — semantic, structured markup
- **CSS3** — custom design system built with CSS variables and theming, responsive layouts using CSS Grid and Flexbox, no external CSS framework
- **Vanilla JavaScript** — DOM manipulation, event handling, collapsible/interactive UI components (no libraries such as jQuery)

No build tools, frameworks, or backend are used in these projects. Each site is a fully self-contained HTML file.

## How to View

These projects were built and tested as standalone, offline web pages. To view any of them:

1. Clone or download this repository
2. Open the desired `.html` file directly in any modern web browser

They are not currently deployed to a live server, but can be hosted on any static hosting platform (e.g. GitHub Pages, Netlify, Vercel) with no modification required.

## Why I Built These

I built these projects independently, without being assigned to do so, because I enjoy the process of taking a complex body of content (in this case, entire school curricula) and turning it into something structured, navigable, and genuinely useful for a learner. I see this as the same kind of problem-solving instinct that drives my academic research, applied to a different medium.

I am currently expanding this foundation toward modern frameworks (React, Next.js), version control workflows, and low-code/automation platforms, and I welcome any feedback on the code in this repository.
